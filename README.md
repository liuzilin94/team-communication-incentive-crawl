## 使用规范

### 1. 分支命名

| 分支 | 成员 |
|------|------|
| `liuzilin` | 刘耙琳 |
| `chenxia` | 陈霞 |
| `make` | 马珂 |
| `tuolehanni` | 托勒哈尼阿依·巴塔别克 |

每位成员在自己的分支下工作，**不要直接提交到 main**。

### 2. 目录结构规范

每本书按以下结构存放（以《鄂国金佛簪编》为例）：

```
丛书名/
├── README.md              ← 本书目转存说明
├── metadata.json          ← 元数据：卷数、字数、来源
├── 目录结构说明.txt
├── 卷首.txt         ← 序言、凡例等
└── 卷一.txt ~ 卷N.txt  ← 正文各卷
```

### 3. 文件命名规范

| 内容 | 命名规则 | 示例 |
|------|------|------|
| 卷首 | `卷首.txt` | `卷首.txt` |
| 正文卷 | `卷X.txt` （**汉字数字**） | `卷一.txt`、`卷二十八.txt` |
| 目录说明 | `目录结构说明.txt` | `目录结构说明.txt` |
| 元数据 | `metadata.json` | `metadata.json` |

> :warning: 禁止使用阿拉伯数字！必须使用**汉字数字**（卷一、卷二十八，**不是** 卷1、卷28）

### 4. TXT 内容规范

- **编码格式**：`UTF-8`（无 BOM）
- **换行符**：Unix 风格（LF, `\n`）
- **无乱码**：文字内容可正常阅读
- **分页处理**：保留原书分页标记（如 `○` 或 `□□□`）
- **每卷独立**：每卷单独存为一个文件，不合并

### 5. metadata.json 格式

```json
{
  "title": "鄂国金佛簪编",
  "volume_count": 28,
  "source_url": "https://zh.wikisource.org/wiki/...",
  "source": "维基文库·四库全书本",
  "author": "宋 岳珂 撰",
  "total_characters": 123160,
  "crawled_by": "刘耙琳",
  "crawl_date": "2026-09-11",
  "notes": []
}
```

### 6. 书目清单表格填写规范

在 `第4组.xlsx` 中，每本书需填写：

| 列 | 字段 | 示例 |
|----|------|------|
| F | 爬取网址 | `https://zh.wikisource.org/wiki/...` |
| G | 是否爬取成果 | `已完成（28卷 / 123,160字）` |
| H | 出版社 | `维基文库（无纸质出版社）` |
| I | 出版版别 | `四库全书本（宋 岳珂 撰）` |

### 7. 质量检查清单

每本书上传前确认：
- [ ] 每卷内容完整，无截断
- [ ] 文件名为**汉字数字**（卷一~卷二十八）
- [ ] UTF-8 编码，无乱码
- [ ] `metadata.json` 已填写完整
- [ ] `目录结构说明.txt` 已创建
- [ ] `书目清单.xlsx` 表格 F/G/H/I 列已更新
